# 介護保険事業所検索（全国版）

都道府県 → 市区町村（政令指定都市は区も）を選んで、介護保険事業所を
サービスの種類・事業所名・住所・法人名で探せる検索ページです。

- 公開URL：https://start-reposi.vercel.app/kaigo
- 元のURL（GitHub Pages）：https://sonosannworks.github.io/kaigo-search/
- 出典：厚生労働省「介護サービス情報公表システム」オープンデータ
  https://www.mhlw.go.jp/stf/kaigo-kouhyou_opendata.html
- 制作：sonosann Web&AIサポート（https://sonosann-webai.net/）
- 国や自治体の公式ページではありません。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 検索ページ本体（1ファイル） |
| `build_data.py` | 国のCSVをダウンロードして `data/` を作るプログラム（Python 3.9以上、追加インストール不要） |
| `data/index.json` | 都道府県の一覧・データ時点 |
| `data/{都道府県コード}/index.json` | 市区町村の一覧（件数・区） |
| `data/{都道府県コード}/{市区町村コード}.json` | その市区町村の事業所 |
| `.nojekyll` | GitHub Pages でそのまま公開するための空ファイル |

ページを開いた人は、選んだ市区町村のファイルだけを読み込みます（全国分を一度に読み込みません）。

## データの更新（年2回：1月中旬・7月中旬）

国のデータは「6月末時点」「12月末時点」で年2回更新されます。

```
python build_data.py
git add -A
git commit -m "データ更新（20XX年X月末時点）"
git push
```

`build_data.py` が国のページから最新のCSV（約35ファイル）を探してダウンロードし、
`data/` を作り直します。最後に件数・ファイル数・合計サイズが表示されます。

そのほかの使い方：

- `python build_data.py --save-csv csv` … ダウンロードしたCSVを `csv/` に保存する（`csv/` はGitに入りません）
- `python build_data.py --csv-dir csv` … 保存済みのCSVから作り直す（ダウンロードしない）

## 変換で自動的に直しているところ

- 全角の英数字・記号を半角に（例：`（096）351-8088` → `096-351-8088`）
- ハイフンのない電話番号に区切りを入れる
- 住所の頭に都道府県・市区町村がない場合は補う／「熊本市熊本市北区…」のような重複を取る
- ホームページURLの書き間違い（`htpp://` など）を直し、使えないものは外す
- 日本の外や、市区町村の中心から約60km以上離れた位置情報は使わない（地図は住所で開く）
- 同じ事業所の重複行を除く
- 「介護療養型医療施設」（2024年3月末で廃止）は載せない

## 利用上の注意

国のオープンデータの利用規約に沿って利用しています。
電話番号・営業日などは変わることがあるため、ページ上でも「事前に各事業所へ確認」と案内しています。
